## Sobre o projeto

O Athenyx NexusHub é um sistema simples para controle de veículos.

Nele é possível cadastrar veículos, visualizar os dados em uma tabela, filtrar por status, editar o status e excluir registros.

## Tecnologias usadas

- HTML
- CSS
- Bootstrap
- JavaScript

## Observação

Os dados cadastrados ficam salvos no próprio navegador usando localStorage.
Assim, mesmo atualizando a página, os veículos continuam aparecendo na tabela.
